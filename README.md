# 한양 숨바꼭질 (hyde-seek-like)

MazM 「하이드 앤 씨크」의 게임 방식(보드 이동 + 카드 전투 + 스토리 선택지)을 본뜬 조선풍 도트 게임. 고도(Godot) 4.3.

- 주인공: 누명을 쓰고 남장한 채 쫓기는 소녀 연이(연돌이)
- 그래픽: `tools/gen_ui.py`가 오픈 라이선스 원본(assets-raw 브랜치)을 한지·목각·먹 붓 느낌으로 가공 (출처는 CREDITS.md)
- 빌드: main에 올리면 GitHub Actions가 APK를 만들어 Releases에 올림

1. ✅ 뼈대: 타이틀 → 프롤로그 → 한양 지도 보드 → 카드 전투 → 1장 끝
2. ✅ 카드 합성(★1~3)·전리품 고르기·운종가 장터, 상반신 초상화
3. ✅ v0.3 조선풍 개편: 한지 질감·목각 테두리·놋쇠 장석, 송명·고운바탕 글꼴, 상소문 카드, 먹 붓 아이콘, 수선전도 보드, 주인공 이름 정하기
4. ✅ v0.4 일러스트: 주인공·남장 표정 8장, 허 의원, 그림자 사내, 포졸, 보드 NPC 4명, 순라꾼, 배경 7장

6. ✅ v0.6: 저장 칸 3개+자동 저장(5분·앱 종료·화면 전환), 이어하기, 변장 이름 정하기, 엽전으로 상소 단련, 깨끗한 한지 질감, 데포르메 앱 아이콘, 한자 글꼴

8. ✅ v0.8: 제2~5장 이야기(남장·왈패 소굴·대대장·어의), 종사관 윤도결·왈패 대장 서휘·대대장 백운·최종 보스 검은 사내, 동료 전투, 장별 보드 4개. 새 인물은 도트 임시 그림(준비중)
